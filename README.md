# 🎯 Python Quiz App

**Python Quiz App** is an interactive quiz application developed by **Dhruvi** using Python. The project is designed to provide users with a simple, engaging, and user-friendly platform to test their knowledge through multiple-choice questions.

The application features a **Graphical User Interface (GUI)** that makes the quiz easy to navigate and visually interactive. Users can read each question, select an answer from the available options, and move through the quiz using the provided controls.

The application automatically evaluates the selected answers and keeps track of the user's score throughout the quiz. Once all questions have been completed, a **final scorecard** is displayed, allowing the user to see their total score and understand their overall performance.

## ✨ Features

* 📝 Multiple-choice quiz questions
* 🖥️ Interactive and user-friendly GUI
* ✅ Automatic answer validation
* 📊 Real-time score calculation
* 🏆 Final scorecard displaying the user's result
* 🔄 Easy navigation between questions
* 🎨 Clean and simple user interface
* ⚡ Fast and lightweight Python application

## 🛠️ Technologies Used

* **Python** – Used for the core application logic.
* **GUI Framework** – Used to design and implement the graphical user interface.
* **Python Conditional Logic** – Used for checking answers and calculating scores.
* **Event Handling** – Used to manage user interactions with the quiz interface.

## 🚀 How It Works

1. The application starts with the quiz interface.
2. A question is displayed along with multiple answer choices.
3. The user selects the answer they believe is correct.
4. The application checks the selected answer.
5. The score is updated based on the user's response.
6. The process continues until all questions have been answered.
7. At the end of the quiz, a **scorecard** is generated displaying the user's final result.

## 📊 Scorecard

The scorecard is an important part of the application. It provides immediate feedback after the quiz is completed by displaying the user's final score. This makes it easy for users to evaluate their performance and see how many questions they answered correctly.
